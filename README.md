# financial_equity_graph

用有向图做**股权穿透**的 Python 实验项目：给定公司之间的持股关系，计算每个主体对目标公司的**最终（直接 + 间接）持股比例**，找出**关键持股路径**，并尝试处理**交叉持股形成的环路**。

项目以学习 / 算法验证为目的，使用硬编码的示例数据，没有数据接入或持久化。

## 功能

- 多层股权结构的最终持股比例计算
- 关键控制路径（持股比例乘积最大的路径）及其所在层级
- 交叉持股环路的识别与闭式求解
- 基于矩阵求逆的独立解法，用于校验上述结果

## 核心概念

### 图的表示

- `EntityNode`：节点，代表公司或股东。
- `EquityEdge(股东, 被投资方, 持股比例)`：有向边。例如 `EquityEdge(v1, v0, 0.0449)` 表示 **v1 持有 v0 的 4.49%**。注意构造参数中 `headNode` 是股东，`tailNode` 是被投资方，与常规图论中 head/tail 的约定相反。
- 遍历方向：从目标公司沿 `inEdges` 向上找到其股东，逐层展开。

### 节点字段

| 字段              | 含义                                          |
| ----------------- | --------------------------------------------- |
| `u`             | 当前层累计的持股贡献                          |
| `pre_u`         | 上一层累计值（供下一层使用）                  |
| `v`             | 最终持股比例（所有层的贡献累加）              |
| `w` / `cur_w` | 关键路径的对数权重，`w = Σ(-ln(持股比例))` |
| `key_l`         | 关键路径所在的层数                            |
| `degree_o`      | 出度，用于拓扑排序式的环路检测                |

边的 `lnWeight = -ln(weight)` 把「持股比例乘积最大」的最强控制路径转化为「权重和最小」的最短路径问题。

`PseudoEdge` 是一条虚拟根边，给目标节点注入 `pre_u = 1`，作为分层遍历的起点。

## 示例股权结构

`main.py` 和 `test.py` 中使用的示例（股东 → 被投资方）：

```
v1 --4.49%--> v0        v2 --4.56%--> v0
v3 --20.83%-> v0        v4 --2.92%--> v0
v5 --4.61%--> v0

v1 --90%----> v2        v6 --90%----> v1
v6 --10%----> v2
v1 --20.2%--> v3        v2 --78%----> v3
```

`test.py` 在此基础上额外加入 `v2 --10%--> v1`，形成 v1 ↔ v2 交叉持股的环路。

结构示意：

```
v0 (目标公司)
├── v1  4.49% ──┬── v6  90%
│               └── [test.py] v2  10%（环路）
├── v2  4.56% ──┬── v1  90%
│               └── v6  10%
├── v3 20.83% ──┬── v1  20.2%
│               └── v2  78%
├── v4  2.92%
└── v5  4.61%
```

## 算法

### 1. 分层 BFS 动态规划 —— `main.py`

从目标公司开始逐层向上遍历股东：

1. 对本层每条边 `e`，将其头节点 `e.headNode` 的贡献累加：
   `u += e.weight * e.tailNode.pre_u`
2. 层遍历结束后执行 `update()`：
   `pre_u = u`，`v += u`，`u = 0`
3. 同时更新关键路径：若 `tailNode.w + lnWeight < node.w`，则记录 `cur_w` 和 `key_l`。

`v` 最终等于该主体到目标公司所有路径的持股比例乘积之和。以无环示例为例：

| 节点 | v          | 说明                                                  |
| ---- | ---------- | ----------------------------------------------------- |
| v1   | 0.2742432  | 4.49% + 90%×4.56% + 20.2%×20.83% + 90%×78%×20.83% |
| v2   | 0.208074   | 4.56% + 78%×20.83%                                   |
| v3   | 0.2083     | 直接持股                                              |
| v4   | 0.0292     | 直接持股                                              |
| v5   | 0.0461     | 直接持股                                              |
| v6   | 0.26762628 | 所有路径贡献之和                                      |

关键路径示例：v1 的最大持股乘积路径为 `v1 → v2 → v3 → v0`（乘积 14.6227%），对应 `w = 1.9226`，`key_l = 3`。

### 2. 环路检测与闭式求解 —— `test.py`

在分层遍历基础上增加了：

- 利用 `degree_o` 和边的 `visited_times` 模拟拓扑排序，找出无法消解、受环路影响的节点
- 用 DFS（`findCycle`）找出具体环路
- `handleCycle()` 用等比级数闭式解处理环：设环上边的权重乘积为 `p`，放大因子 `c = p / (1 - p)`，则
  `v = (环外贡献 + 环内上游贡献) × (1 + c)`

`test.py` 中环路示例的结果为 `v1 = 0.30136615`、`v2 = 0.23821062`，与矩阵法一致。

### 3. 矩阵法 —— `ios.py`

把持股关系写成矩阵 `A`（行 = 股东，列 = 被投资方），利用级数展开：

```
A + A² + A³ + … = A(I − A)⁻¹
```

`C = A · B` 的第一列即各主体对 v0 的最终持股比例。该方法天然支持任意环路（前提是谱半径小于 1），常用作结果校验基准。

## 运行

环境：Python 3.6+。`main.py` 和 `test.py` 无第三方依赖，`ios.py` 需要 numpy。

```bash
python3 main.py    # 分层动态规划，无环示例
python3 test.py    # 含环路检测与求解
python3 ios.py     # 矩阵法结果
```

两个脚本都会打印逐层遍历的中间过程，最后输出每个节点的 `v`（最终持股比例）。

### 构建自己的图

```python
from EntityNode import EntityNode
from EquityEdge import EquityEdge
from main import levelOrder3

v0 = EntityNode('v0', 'v0')
v1 = EntityNode('v1', 'v1')
EquityEdge(v1, v0, 0.3)   # v1 持有 v0 的 30%

levelOrder3(v0)
print(v1.v)               # 0.3
```
